# Переключатель города в прайс-листе

## Проблема

Цена съёмки зависит от города: в Гюмри дешевле, в Ереване дороже. Сейчас в
блоке «Прайс» на главной у каждого тарифа одна цена на оба города.

## Решение

Добавить в блок `Pricing` переключатель города (Гюмри / Ереван). Список того,
что входит в тариф (фичи), общий для обоих городов — меняется только цена.
Сноска про доплату за доп. фото в ретуши (сейчас `1500 ֏`) тоже общая, от
города не зависит.

### Цены

| Тариф   | Гюмри     | Ереван    |
|---------|-----------|-----------|
| STANDARD| 40 000 ֏  | 50 000 ֏  |
| EXPRESS | 25 000 ֏  | 35 000 ֏  |

## Модель данных (`content/types.ts`)

```ts
pricing: {
  heading: string;
  cityToggle: { gyumri: string; yerevan: string }; // подписи на кнопках
  tiers: {
    name: string;
    priceByCity: { gyumri: string; yerevan: string };
    features: string[];
  }[];
  footnote: string;
};
```

`price: string` заменяется на `priceByCity: { gyumri, yerevan }` у каждого
тарифа. `cityToggle` — новое поле с подписями кнопок (RU: «Гюмри» / «Ереван»,
EN: «Gyumri» / «Yerevan»).

## Компонент `Pricing.tsx`

- `useState<'gyumri' | 'yerevan'>('yerevan')` — по умолчанию выбран Ереван
  (более дорогой город, вероятно основная аудитория).
- Над сеткой карточек тарифов — два pill-кнопки в стиле сайта: моно-шрифт,
  uppercase tracking-wider (как подписи тарифов STANDARD/EXPRESS). Активная
  кнопка — заливка `bg-wine text-paper`, неактивная — рамка `border-ink/15`
  без заливки.
- Клик по кнопке меняет состояние; отображаемая цена в обеих карточках
  берётся как `tier.priceByCity[selectedCity]`.
- Список фич и структура карточек не меняются.

## Тестирование

`Pricing.test.tsx`:
- по умолчанию видна ереванская цена для обоих тарифов;
- клик по кнопке «Гюмри» переключает цену на гюмринскую в обеих карточках
  одновременно;
- кнопки переключателя — доступные (`<button>`, видны в
  `getByRole('button')`).

`content/content.test.ts` (bilingual parity): обновить проверку структуры под
`priceByCity` вместо `price`.

## Вне рамок задачи

- Персистентность выбора города между визитами (localStorage) — не нужна,
  можно добавить позже, если попросят.
- Влияние выбора города на что-либо за пределами блока `Pricing` (контакты,
  hero и т.д.) — не требуется.
